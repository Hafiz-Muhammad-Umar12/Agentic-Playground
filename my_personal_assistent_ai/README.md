# 🤖 ZAIN KA PERSONAL ASSISTANT

**Version:** 1.0  
**Language:** Urdu + English (Hinglish)  
**Platform:** Windows / Linux / Mac

---

## 📦 INSTALL KAISE KARO

### Step 1 — Python Install Karo
Agar Python nahi hai toh yahan se download karo:
👉 https://python.org/downloads
(Version 3.8 ya usse upar chahiye)

Install karte waqt **"Add Python to PATH"** wala box zaroor tick karo!

### Step 2 — Assistant Chalao

**Windows pe:**  
`START_ASSISTANT.bat` file pe double-click karo — bas!

**Ya CMD/Terminal se:**
```
python assistant.py
```

## 💬 SAARE COMMANDS

### 📁 Folder Commands
| Command | Kaam |
|--------|------|
| `folder bana C:\Test` | Naya folder banao |
| `folder kholo C:\Test` | Folder ki files dekho |
| `folder delete C:\Test` | Folder delete karo |

### 📄 File Commands
| Command | Kaam |
|--------|------|
| `file delete C:\Test\file.txt` | Ek file delete karo |
| `files delete C:\Test` | Folder ki saari files delete karo |
| `rename purana.txt naya.txt` | Rename karo |

### 💻 System Commands
| Command | Kaam |
|--------|------|
| `pc off` | Computer band karo |
| `pc restart` | Restart karo |
| `open notepad` | Notepad kholo |
| `open chrome` | Chrome kholo |
| `time` | Abhi ka waqt dekho |
| `disk` | Disk space dekho |

### 😊 Mood Commands
Bas yeh likho aur assistant help karega:
- `main sad hoon` → Motivation milegi (Audi 2030! 🚗)
- `main bahut tension mein hoon` → Encouragement milega
- `main khush hoon` → Double khushi!

### 🔧 Other
| Command | Kaam |
|--------|------|
| `help` | Saare commands dekho |
| `exit` | Assistant band karo |

## ❓ PROBLEMS

**"python not found" error aaye:**
→ Python dobara install karo, PATH wala option tick karo

**PC off nahi ho raha:**
→ CMD ko Admin mode mein chalao (Right click → Run as Administrator)

**Voice nahi aa rahi:**
→ Koi baat nahi, text mein kaam karta hai
